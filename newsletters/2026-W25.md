## Datasette Ecosystem

A flurry of Datasette releases this week — if you use it for data publishing or internal tooling, there is a fair amount to update.

**[Datasette Apps: Host custom HTML applications inside Datasette](https://simonwillison.net/2026/Jun/18/datasette-apps/#atom-everything)** — 2026-06-18

The headline feature of the week: Datasette Apps lets you embed self-contained HTML applications directly inside a Datasette instance, enabling lightweight interactive tools alongside your data. The 0.1a2 and 0.1a3 alpha releases dropped earlier in the week ahead of this writeup. Early days, but the concept of co-locating small apps with their underlying data is genuinely useful.

**[datasette-agent 0.3a0](https://simonwillison.net/2026/Jun/15/datasette-agent/#atom-everything)** — 2026-06-15

An alpha update to the LLM agent plugin for Datasette. The agent layer allows natural-language querying against Datasette-hosted databases, which pairs naturally with the new Apps functionality.

**[datasette-acl 0.6a0](https://simonwillison.net/2026/Jun/18/datasette-acl/#atom-everything)** — 2026-06-18

Access-control improvements for Datasette, now at 0.6a0. If you are running Datasette in any multi-user or public-facing context, keeping ACL up to date is non-negotiable.

**[datasette-tailscale 0.1a0](https://simonwillison.net/2026/Jun/16/datasette-tailscale/#atom-everything)** — 2026-06-16

A new plugin integrating Datasette with Tailscale for network-level access control. First alpha, so expect rough edges, but the combination of Tailscale's zero-config VPN and Datasette's data publishing is a reasonable pattern for internal tooling.

**[datasette 1.0a34](https://simonwillison.net/2026/Jun/16/datasette/#atom-everything)** — 2026-06-16

Another alpha on the slow march toward a 1.0 stable release. Changelog details at the link; worth scanning if you are tracking breaking changes ahead of the eventual stable.
