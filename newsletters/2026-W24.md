# AI Tooling & R Ecosystem Weekly Digest

A week dominated by Anthropic's new model releases, some policy turbulence, and a handful of useful developer tooling updates.

## Claude Fable / Mythos: Impressions and Concerns

**[Initial impressions of Claude Fable 5](https://simonwillison.net/2026/Jun/9/claude-fable-5/#atom-everything)** — date unavailable

Simon Willison's first take on Claude Fable 5, Anthropic's latest model release. The post covers early capability observations and sets context for the wave of follow-up commentary that dominated the week.

**[What it feels like to work with Mythos](https://www.oneusefulthing.org/p/what-it-feels-like-to-work-with-mythos)** — 2026-06-09

Ethan Mollick's assessment of working with Mythos, framing it as another meaningful capability jump rather than an incremental update. The piece focuses on qualitative experience rather than benchmarks, which makes it a useful counterpoint to more technical write-ups.

**[Claude Fable is relentlessly proactive](https://simonwillison.net/2026/Jun/11/fable-is-relentlessly-proactive/#atom-everything)** — date unavailable

Willison observes that Fable 5 exhibits notably more proactive behavior than previous Claude versions, taking initiative in ways that are sometimes useful and sometimes not. Worth reading alongside the next item.

**[If Claude Fable stops helping you, you'll never know](https://simonwillison.net/2026/Jun/10/if-claude-fable-stops-helping-you/#atom-everything)** — date unavailable

A pointed concern: Fable's refusal behavior is apparently silent enough that users may not realize when the model has declined to assist. This is a non-trivial usability and trust problem, particularly for developers building applications on top of it.

## Policy and Governance

**[Anthropic Walks Back Policy That Could Have 'Sabotaged' AI Researchers Using Claude](https://simonwillison.net/2026/Jun/11/anthropic-walks-back-policy/#atom-everything)** — date unavailable

Anthropic apparently introduced, then reversed, a policy that would have restricted how researchers could interact with Claude in ways that could have interfered with legitimate AI safety and capability research. The reversal followed pushback, but the episode raises questions about how such policies get introduced in the first place.

**[Statement on the US government directive to suspend access to Fable 5 and Mythos 5](https://simonwillison.net/2026/Jun/13/us-government-directive-to-suspend-access/#atom-everything)** — date unavailable

A US government directive to suspend access to Fable 5 and Mythos 5 prompted a formal statement from Anthropic. The details of the directive's scope and rationale are worth tracking; this kind of government intervention in frontier model access is relatively new territory.

## LLM Tooling

**[llm 0.32a3](https://simonwillison.net/2026/Jun/9/llm/#atom-everything)** — date unavailable

A new alpha release of Willison's `llm` command-line tool. The `llm` package remains one of the more practical ways to script interactions with multiple model providers from the terminal or Python.

**[datasette-agent 0.2a0](https://simonwillison.net/2026/Jun/10/datasette-agent/#atom-everything)** — date unavailable

An alpha update to the Datasette agent plugin, which allows LLM-driven querying and interaction with Datasette instances. The 0.2 version suggests the architecture is stabilizing after initial experimentation.

**[datasette-agent-edit 0.1a0](https://simonwillison.net/2026/Jun/7/datasette-agent-edit/#atom-everything)** — date unavailable

A companion plugin to datasette-agent that adds editing capabilities, letting an agent write back to a Datasette database rather than just querying it. First release, so expect rough edges.

**[Setting a custom price for a model in AgentsView](https://simonwillison.net/2026/Jun/9/agentsview-custom-model-price/#atom-everything)** — date unavailable

A small but practical addition to AgentsView: the ability to set custom pricing for models, useful when running local or private deployments where default cost estimates don't apply.

**[OpenAI WebRTC Audio Session, now with document context](https://simonwillison.net/2026/Jun/12/openai-webrtc/#atom-everything)** — date unavailable

Willison's WebRTC audio session tool for OpenAI's realtime API now supports passing document context into the session. A useful incremental improvement for anyone building voice interfaces that need to reference structured content.

## Developer Infrastructure

**[datasette 1.0a33](https://simonwillison.net/2026/Jun/11/datasette/#atom-everything)** — date unavailable

Another alpha toward Datasette 1.0. The project has been in extended alpha for some time, but each release continues to refine the API and plugin system.

**[Mapping SQLite result columns back to their source table.column](https://simonwillison.net/2026/Jun/13/sqlite-column-provenance/#atom-everything)** — date unavailable

A technical deep-dive into tracking which table and column a result value originated from in SQLite queries. Useful context for anyone building tools that need to present query results with meaningful provenance information.

**[Publishing WASM wheels to PyPI for use with Pyodide](https://simonwillison.net/2026/Jun/13/publishing-wasm-wheels/#atom-everything)** — date unavailable

A practical guide to packaging Python code as WebAssembly wheels and publishing them to PyPI so they can be consumed by Pyodide in the browser. Relevant for anyone building browser-based Python tooling.

**[DiffusionGemma](https://simonwillison.net/2026/Jun/10/diffusiongemma/#atom-everything)** — date unavailable

Coverage of DiffusionGemma, Google's diffusion-based language model in the Gemma family. Diffusion-based text generation remains an active research area, and a production-adjacent release from Google is worth watching.

**[Siri AI at WWDC 2026](https://simonwillison.net/2026/Jun/8/wwdc/#atom-everything)** — date unavailable

Willison's notes on Apple's AI announcements at WWDC 2026. The piece is presumably measured given Apple's historically slow pace on this front; useful as a reference point for what Apple is and isn't shipping.
