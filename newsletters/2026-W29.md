# AI Tooling & R Ecosystem Weekly Digest

A relatively busy week for LLM tooling updates, a meaningful R package release, and a notable security demonstration worth knowing about.

---

## R Packages

### [ellmer 0.4.2](https://github.com/tidyverse/ellmer/blob/HEAD/NEWS.md#ellmer-0-4-2) — 2026-07-17

A substantial maintenance release for the tidyverse LLM interface package. Default models have been bumped across nearly every provider — Claude Sonnet 4.6, GPT-5, Gemini 3.5 Flash, and others — so existing code will quietly start using newer models on next run. New additions include `chat_posit()` for Posit-hosted models via OAuth, `batch_chat()` support for Gemini and Groq, and a `set_model()` method for changing models after chat creation. Truncated or filtered responses now surface warnings rather than failing silently, which is a welcome improvement for production use.

## LLM Tooling

### [Claude Code uses Bun written in Rust now](https://simonwillison.net/2026/Jul/19/claude-code-in-bun-in-rust/#atom-everything) — NA

Simon Willison covers the runtime shift in Claude Code's underlying stack. The move to Bun (itself implemented in Zig and linked against Rust components) signals Anthropic continuing to optimize the CLI tool's performance and startup time. Worth watching if you depend on Claude Code in automated pipelines.

### [Inkling: Our open-weights model](https://simonwillison.net/2026/Jul/16/inkling/#atom-everything) — NA

A new open-weights model release covered by Willison. Open-weights releases remain significant for practitioners who need local inference or reproducibility guarantees without API dependency. Details on size, licensing, and benchmark positioning are worth checking before committing to an integration.

### [Kimi K3, and what we can still learn from the pelican benchmark](https://simonwillison.net/2026/Jul/16/kimi-k3/#atom-everything) — NA

Willison uses the release of Moonshot AI's Kimi K3 as a hook for a broader point about benchmark design and what simple, stable evaluations can still reveal about model behavior. A useful corrective against benchmark fatigue.

## Security

### [How I tricked Claude into leaking your deepest, darkest secrets](https://simonwillison.net/2026/Jul/15/claude-web-fetch-exfiltration/#atom-everything) — NA

A concrete demonstration of prompt injection via web fetch in Claude — an attacker-controlled page causes the model to exfiltrate conversation context. The attack class is not new, but this is a clear, reproducible example relevant to anyone building agentic workflows that let models fetch external URLs. If your application does this, read it.

## SQLite & Data Infrastructure

### [lobste.rs is now running on SQLite](https://simonwillison.net/2026/Jul/14/lobsters-sqlite/#atom-everything) — NA

The link-aggregator community site migrated its production database to SQLite, adding to the growing list of real-world deployments that have made this move. Relevant context for anyone still treating SQLite as a toy database unfit for production web traffic.

### [SQLite Query Explainer](https://simonwillison.net/2026/Jul/18/sqlite-query-explainer/#atom-everything) — NA

A tool for making SQLite's EXPLAIN output more readable. Useful for anyone doing performance work on SQLite-backed applications, where the raw EXPLAIN output is notoriously terse.
