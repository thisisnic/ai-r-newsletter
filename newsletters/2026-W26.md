# AI Tooling & R Ecosystem Weekly Digest

A week heavy on security thinking, SQLite tooling milestones, and a useful benchmark result for anyone using LLMs with data visualizations.

---

## LLM Capability

**[LLMs are getting much better at interpreting counterintuitive plots](https://simonpcouch.com/blog/2026-06-19-bluffbench-saturation/)** — 2026-06-19

Simon Couch and Sara Altman report on BluffBench, a benchmark testing whether LLMs can correctly interpret plots that violate conventional visual expectations — inverted axes, reversed color scales, and similar traps. Recent models are saturating the benchmark in ways earlier ones did not, which has practical implications for anyone piping ggplot output into an LLM-assisted workflow. The post is cross-published on the Posit Open Source Blog and is worth reading if you use LLMs for exploratory data analysis review.

## SQLite Tooling

**[sqlite-utils 4.0rc1 adds migrations and nested transactions](https://simonwillison.net/2026/Jun/21/sqlite-utils-40rc1/)** — date not available

The 4.0 release candidate of sqlite-utils introduces schema migrations and nested transaction support, two long-requested features for anyone using it as a lightweight database layer in Python or alongside Datasette. The migration support in particular closes a significant gap for projects that evolve their schemas over time. Worth testing against your existing scripts before the final release.

**[datasette 1.0a35](https://simonwillison.net/2026/Jun/23/datasette/)** — date not available

Another alpha in the slow march toward Datasette 1.0, continuing to stabilize the plugin API and core behavior. No single headline feature, but incremental progress on what will eventually be a stable release target for tools built on top of it.

**[datasette-export-database 0.3a2](https://simonwillison.net/2026/Jun/25/datasette-export-database/)** — date not available

A plugin for exporting entire Datasette databases moves to 0.3a2. Useful for anyone who needs to hand off a SQLite file from a running Datasette instance without direct filesystem access.

## Security & Prompt Injection

**[Prompt Injection as Role Confusion](https://simonwillison.net/2026/Jun/22/prompt-injection-as-role-confusion/)** — date not available

A conceptual framing of prompt injection attacks: rather than treating them as input-sanitization failures, this post argues they are fundamentally a role confusion problem — the model cannot reliably distinguish between instructions from the developer and content from untrusted sources. The framing has practical implications for how you architect agentic systems and where you place trust boundaries.

**[What happened after 2,000 people tried to hack my AI assistant](https://simonwillison.net/2026/Jun/26/hack-my-ai-assistant/)** — date not available

A first-hand account of running a public prompt injection challenge and analyzing the attempts. The volume and variety of attack patterns are instructive, and the post is honest about which defenses held and which did not. Required reading if you are shipping anything with a user-facing LLM component.

**[Incident Report: CVE-2026-LGTM](https://simonwillison.net/2026/Jun/26/incident-report/)** — date not available

A write-up of a security incident with a name that implies AI-assisted code review played a role in missing the vulnerability. The details make a pointed case about over-trusting automated approval signals. Treat it as a cautionary note alongside any CI pipeline that uses LLMs to flag or clear security issues.

## Infrastructure & Browser Tooling

**[Temporary Cloudflare Accounts for AI agents](https://simonwillison.net/2026/Jun/21/temporary-cloudflare-accounts/)** — date not available

Cloudflare is offering ephemeral account contexts for AI agents — isolated environments that can be spun up and discarded, limiting the blast radius of an agent that does something unintended. A sensible architectural primitive for agentic workflows that need network access.

**[Porting the Moebius 0.2B image inpainting model to run in the browser with Claude Code](https://simonwillison.net/2026/Jun/22/porting-moebius/)** — date not available

A practical walkthrough of using Claude Code as a porting assistant to get a small image inpainting model running client-side via WebAssembly. The process is as interesting as the result — it documents where AI-assisted porting helps and where it still requires manual intervention.
