# AI Tooling & R Ecosystem Weekly Digest

A busy week in LLM tooling: new model releases, a minor price war, and several incremental but useful updates to the `llm` CLI ecosystem.

---

## LLM Models & the Market

**[Claude Opus 5.5, GPT-6 Sol, GPT-6 Luna, and a new price war](https://simonwillison.net/2026/Sep/22/opus-and-sol-and-luna/)** — NA

Multiple frontier model releases landed in the same window, with Anthropic and OpenAI apparently trying to undercut each other on pricing. The piece covers what differentiates the new variants and what the pricing moves might signal about margin pressure at the top of the market. Worth reading if you're budgeting API costs for production workloads.

**[Bonsai 2 27B: Near-Lossless Compression in a 9x Smaller Footprint](https://simonwillison.net/2026/Sep/17/hn-49747390/)** — NA

A 27B-parameter model claiming near-lossless quality at roughly one-ninth the size of its source model. If the benchmarks hold up under scrutiny, this is the kind of compression result that makes local deployment of capable models considerably more practical.

**[Jev introduces a new shape of LLM - System One, aka Decision Models](https://simonwillison.net/2026/Sep/21/jev/)** — NA

A framing worth paying attention to: "Decision Models" as a distinct architecture from standard generation-focused LLMs, oriented around fast, low-latency judgment calls rather than extended reasoning. The System One label is doing a lot of conceptual work here, and it's unclear yet whether this is a genuine architectural distinction or marketing.

## LLM CLI Tooling Updates

**[llm 0.36](https://simonwillison.net/2026/Sep/22/llm/)** — NA

The `llm` command-line tool picked up new features in this release. If you run LLM workflows from the terminal or integrate `llm` into scripts, checking the changelog is worthwhile — these point releases tend to add meaningful capability without much fanfare.

**[llm-anthropic 0.29](https://simonwillison.net/2026/Sep/22/llm-anthropic/)** — NA

The Anthropic plugin for `llm` updated alongside the core release, presumably adding support for the new Claude Opus 5.5 model. Keep both in sync if you're on the Anthropic stack.

**[llm-typesafe 0.1a0](https://simonwillison.net/2026/Sep/22/llm-typesafe/)** — NA

An early alpha plugin for `llm` focused on typed, structured outputs. Structured output support has become a baseline expectation for production LLM use, so having it as a composable plugin in the `llm` ecosystem is useful even at alpha quality.

**[llm-keys-ui 0.1](https://simonwillison.net/2026/Sep/20/llm-keys-ui/)** — NA

A small UI layer for managing API keys within the `llm` toolchain. Addresses a genuine friction point for anyone juggling multiple provider credentials.

## Datasette

**[datasette 1.0a41](https://simonwillison.net/2026/Sep/24/datasette/)** — NA

Another alpha release on the long road to Datasette 1.0. The project continues to be the most practical tool in the ecosystem for quickly publishing and querying SQLite databases, and each alpha tightens up the API.

**[datasette-explain 0.2.2](https://simonwillison.net/2026/Sep/20/datasette-explain/)** — NA

A plugin update for visualizing SQLite query plans inside Datasette. Useful for debugging slow queries without dropping to the command line.

## Infrastructure & Developer Tooling

**[Cloudflare Python Workers are now generally available](https://simonwillison.net/2026/Sep/21/cloudflare-python-worker/)** — NA

Python support in Cloudflare Workers moves out of beta. This matters for anyone building lightweight LLM-adjacent tools at the edge — you can now run Python-based inference wrappers, prompt routers, or small API handlers without leaving the Workers platform.

**[commit-rewriter 0.2](https://simonwillison.net/2026/Sep/24/commit-rewriter/)** — NA

A tool for rewriting git commit messages, likely using an LLM under the hood. Small utility, but the kind of thing that pays off quickly in codebases where commit hygiene matters.

**[Gemini 3.8 TTS Playground](https://simonwillison.net/2026/Sep/23/gemini-tts-playground/)** — NA

Google released a playground for Gemini 3.8's text-to-speech capabilities. TTS quality has improved enough that it's worth revisiting if you dismissed earlier generations — the playground format makes evaluation low-effort.
