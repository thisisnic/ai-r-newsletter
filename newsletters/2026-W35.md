## R Packages

**[rollama 0.3.1](https://github.com/JBGruber/rollama/blob/HEAD/NEWS.md#rollama-0-3-1)** — 2026-08-24

The R interface to Ollama gains batch image annotation support in `query()`, passing a list of images against a single prompt — useful for document or photo processing workflows. The `think` argument now accepts granular budget levels (`"high"`, `"medium"`, `"low"`, `"max"`) rather than just a boolean, and `output = "data.frame"` now includes `thinking` and `tool_calls` columns from the response.
