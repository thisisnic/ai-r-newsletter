## LLM Tooling

**[llm 0.32rc1 and rc2](https://simonwillison.net/2026/Jul/30/llm-rc1/#atom-everything)** — NA

Two release candidates dropped in quick succession for Simon Willison's `llm` CLI tool, suggesting a stable 0.32 release is close. Worth watching if you run local model workflows from the command line.

**[llm-chat-completions-server 0.1a0](https://simonwillison.net/2026/Jul/30/llm-chat-completions-server/#atom-everything)** — NA

A new plugin that exposes `llm` as an OpenAI-compatible chat completions endpoint. This makes it straightforward to point any client expecting the OpenAI API format at whatever models `llm` has configured locally.

**[llm-mcp-client 0.1a0](https://simonwillison.net/2026/Jul/31/llm-mcp-client/#atom-everything)** — NA

An early-stage MCP client plugin for `llm`, letting the CLI talk to Model Context Protocol servers. Pairs naturally with the stateless MCP work noted below.

**[Stateless MCP has recaptured my interest (and inspired mcp-explorer and datasette-mcp)](https://simonwillison.net/2026/Jul/31/stateless-mcp/#atom-everything)** — NA

Willison writes about renewed interest in stateless MCP servers, which avoid the session management complexity of the original spec. The post covers two new tools: `mcp-explorer` for inspecting MCP servers, and `datasette-mcp` for querying Datasette instances via MCP.

**[Adding a custom MCP server to Claude and ChatGPT](https://simonwillison.net/2026/Jul/29/mcp-in-claude-and-chatgpt/#atom-everything)** — NA

Practical walkthrough of wiring up a custom MCP server to both Claude and ChatGPT. Useful reference now that both platforms support the protocol, though the configuration paths differ between them.

**[smevals - a small eval suite for evaluating models, prompts, and harnesses](https://simonwillison.net/2026/Jul/31/smevals/#atom-everything)** — NA

A lightweight evaluation suite aimed at quick iteration on model and prompt quality rather than comprehensive benchmarking. Likely useful for anyone doing systematic prompt engineering without wanting to stand up a full eval framework.

## R / Data Tooling

**[tidyllm 0.5.2](https://github.com/edubruell/tidyllm/blob/HEAD/NEWS.md#tidyllm-0-5-2)** — 2026-07-30

A substantive bugfix release despite the minor version number. The headline fix is recursive `additionalProperties: false` normalization in JSON schemas, which was causing HTTP 400 rejections from OpenAI, Azure, and OpenRouter-routed requests whenever nested object fields appeared in structured outputs or tool definitions. Provider error messages from OpenAI-compatible gateways are also now properly unwrapped, making these failures actually diagnosable. Additional fixes cover Gemini tool calls, Claude streaming metadata, and cache token reporting across multiple providers.

**[datasette-agent 0.4a0](https://simonwillison.net/2026/Jul/31/datasette-agent/#atom-everything)** — NA

A new alpha of the Datasette agent plugin, which enables LLM-driven querying and exploration of Datasette instances. Alpha status, but worth tracking if you use Datasette for data publishing.

**[datasette-apps 0.2a0](https://simonwillison.net/2026/Aug/1/datasette-apps/#atom-everything)** — NA

Early release of a plugin for bundling small applications inside Datasette. Details are sparse but the direction suggests Datasette is moving toward being a more general app host, not just a data viewer.

**[sqlite-utils 3.39.1](https://simonwillison.net/2026/Jul/26/sqlite-utils/#atom-everything)** — NA

A maintenance release of the SQLite utility library. No major feature additions; routine to keep dependencies current.

## Security

**[AI Worming through Word](https://simonwillison.net/2026/Jul/29/ai-worming-through-word/#atom-everything)** — NA

Coverage of a demonstrated attack using malicious content in Word documents to manipulate AI assistants with file access. Another concrete example of indirect prompt injection in document-processing pipelines, which remain largely undefended at the application layer.

**[Anatomy of a Frontier Lab Agent Intrusion: A Technical Timeline of the July 2026 Incident](https://simonwillison.net/2026/Jul/28/anatomy-of-a-frontier-lab-agent-intrusion/#atom-everything)** — NA

A technical post-mortem of an apparent security incident involving an AI agent at a frontier lab. The timeline format is useful for understanding how agent-driven intrusions differ from conventional attacks, and how quickly things can escalate once an agent has tool access.

**[Investigating three real-world incidents in our cybersecurity evaluations](https://simonwillison.net/2026/Jul/30/three-real-world-incidents/#atom-everything)** — NA

A lab publishes case studies from real incidents surfaced during their security evaluation process. Rare to see this level of detail from an AI organization; useful reading for anyone building threat models around LLM deployments.

**[An Inside Look at the Relay Market Powering Token Resellers and Fraud](https://simonwillison.net/2026/Jul/26/relay-market/#atom-everything)** — NA

An investigation into the gray market for API tokens: how stolen or resold credentials move through relay infrastructure to obscure their origin. Relevant for anyone managing API key exposure or trying to understand anomalous usage patterns.

**[Discovering cryptographic weaknesses with Claude](https://simonwillison.net/2026/Jul/28/discovering-cryptographic-weaknesses-with-claude/#atom-everything)** — NA
