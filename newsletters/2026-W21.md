## LLM Tooling

**[Gemini 3.5 Flash: more expensive, but Google plan to use it for everything](https://simonwillison.net/2026/May/19/gemini-35-flash/#atom-everything)** — NA

Google's latest Flash model comes with a higher price tag than its predecessor, but the company is positioning it as a default across their product surface. Worth watching for anyone tracking cost-per-token trends in production LLM pipelines.

**[llm-gemini 0.32 / 0.32a0](https://simonwillison.net/2026/May/19/llm-gemini-2/#atom-everything)** — NA

Two releases of the llm-gemini plugin this week, with 0.32 landing as the stable release after a brief alpha. These plugins wire Google's Gemini models into Simon Willison's `llm` CLI tool, making it straightforward to run Gemini queries from the command line or scripts.

**[The last six months in LLMs in five minutes](https://simonwillison.net/2026/May/19/5-minute-llms/#atom-everything)** — NA

A compact summary of the LLM landscape since late 2025. Useful as a reference or as something to hand to a colleague who has been heads-down and missed the churn.

**[How fast is 10 tokens per second really?](https://simonwillison.net/2026/May/20/tokens-per-second/#atom-everything)** — NA

A grounding piece that puts token generation speed in human terms — 10 tokens/second is roughly the pace of fast reading aloud, which reframes expectations about latency in interactive applications. Short and worth the two minutes.

## Datasette Agent Cluster

A flurry of alpha releases this week fleshed out an agentic layer on top of Datasette. Taken together, these form a coherent new capability.

**[Datasette Agent](https://simonwillison.net/2026/May/21/datasette-agent/#atom-everything)** — NA

The main writeup introducing Datasette Agent: an LLM-powered interface that can query Datasette instances using natural language, inspect schemas, and iterate on SQL. The conceptual post that ties the alpha releases together.

**[datasette-agent 0.1a1 / 0.1a2 / 0.1a3](https://simonwillison.net/2026/May/14/datasette-agent/#atom-everything)** — NA

Three alpha releases across the week, incrementally building out the core agent plugin. Each release tightened tool definitions and improved how the agent reasons about available tables and query results.

**[datasette-agent-charts 0.1a1 / 0.1a2](https://simonwillison.net/2026/May/20/datasette-agent-charts/#atom-everything)** — NA

A companion plugin that lets the agent render query results as charts. Extends the agent's output beyond raw data tables, which matters for making agentic data exploration more legible to non-technical users.

**[datasette-agent-sprites 0.1a0](https://simonwillison.net/2026/May/21/datasette-agent-sprites/#atom-everything)** — NA

An early alpha adding sprite/icon rendering to agent outputs. More experimental than the charts plugin, but points toward a richer visual layer for Datasette's agentic interface.

**[datasette-llm 0.1a8](https://simonwillison.net/2026/May/19/datasette-llm/#atom-everything)** — NA

Updated alpha of the core datasette-llm plugin, which underpins the agent work. Incremental improvements to how LLM responses are stored and surfaced within Datasette.

**[datasette-llm-accountant 0.1a4](https://simonwillison.net/2026/May/19/datasette-llm-accountant/#atom-everything)** — NA

Tracks token usage and cost across LLM calls made through Datasette. The kind of operational tooling that becomes necessary quickly once you start running agents against real data at any volume.

## Security & Policy

**[FTC to Require Cox Media Group and Others to Pay Nearly $1 Million Over "Active Listening" AI Marketing](https://simonwillison.net/2026/May/22/ftc-active-listening/#atom-everything)** — NA

The FTC settled with Cox Media Group and two other firms over claims that their AI marketing service used device microphones to target ads — a capability the companies apparently advertised to clients. The settlement is modest in dollar terms but notable as a regulatory signal about disclosed versus actual AI data practices.

**[GDS weighs in on the NHS's decision to retreat from Open Source](https://simonwillison.net/2026/May/17/gds-weighs-in/#atom-everything)** — NA

The UK Government Digital Service pushed back on NHS England's reported move away from open-source software. Relevant to anyone in public-sector data infrastructure, and a useful data point on how open-source commitments hold up under procurement pressure.
