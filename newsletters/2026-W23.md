# AI & R Tooling Digest — Early June 2026

A week split between practical tooling releases, a sharp essay on human-AI futures, and a reminder that AI security remains largely unsolved.

---

## LLM Tooling & Platform News

**[Microsoft's new MAI models](https://simonwillison.net/2026/Jun/2/microsofts-new-models/#atom-everything)**
Simon Willison covers Microsoft's release of its MAI model family, adding another entry to an already crowded frontier model landscape. Worth watching to see how these position against OpenAI's own offerings given Microsoft's complicated stake in both.

**[OpenAI Help: Lockdown Mode](https://simonwillison.net/2026/Jun/5/openai-help-lockdown-mode/#atom-everything)**
OpenAI has added a Lockdown Mode option, apparently aimed at users who want tighter controls over what the model can access or share. Details are thin from the frontmatter alone, but it signals growing pressure on platforms to give users more control over AI behavior.

**[Uber Caps Usage of AI Tools Like Claude Code to Manage Costs](https://simonwillison.net/2026/Jun/3/uber-caps-usage/#atom-everything)**
Uber has put usage limits on agentic coding tools including Claude Code, citing cost management. This is an early sign that enterprises adopting AI-assisted development are running into real budget constraints at scale — the economics of agentic workflows are still being worked out.

## Developer Tooling

**[Running Python code in a sandbox with MicroPython and WASM](https://simonwillison.net/2026/Jun/6/micropython-in-a-sandbox/#atom-everything)**
Willison documents an approach to safely executing arbitrary Python code by running MicroPython compiled to WebAssembly, providing meaningful sandboxing without a full container setup. This is directly relevant to anyone building LLM-powered tools that need a code execution environment.

**[datasette 1.0a32](https://simonwillison.net/2026/May/31/datasette/#atom-everything)**
Another alpha release of Datasette on the long road to 1.0, continuing incremental refinement of the SQLite-backed data exploration tool. If you are tracking this project, the changelog is worth a look for API stability signals.

**[datasette-agent-micropython 0.1a0](https://simonwillison.net/2026/Jun/2/datasette-agent-micropython/#atom-everything)**
A new plugin that brings the MicroPython WASM sandbox into Datasette's agent layer, allowing safe code execution within Datasette-powered workflows. Early alpha, but the architecture is interesting for anyone building data agents with execution capabilities.

## Commentary & Broader Takes

**[Co-Existence and the End of Co-Intelligence](https://www.oneusefulthing.org/p/co-existence-and-the-end-of-co-intelligence)** — 2026-06-04
Ethan Mollick revisits the framing of humans and AI as collaborative partners and asks whether that model is still accurate as AI capabilities advance. The piece also includes a practical aside on pitching book ideas to an AI, which is either useful or slightly dispiriting depending on your outlook.

**[AI enthusiasts are in a race against time, AI skeptics are in a race against entropy](https://simonwillison.net/2026/Jun/4/ai-enthusiasts-ai-skeptics/#atom-everything)**
Willison riffs on the asymmetric positions of AI boosters and critics: optimists need things to keep improving fast enough to matter, while skeptics just need the current trajectory to stall or decay. A concise framing worth keeping in mind when reading breathless announcements or dismissive takedowns.

**[The solution might be cancelling my AI subscription](https://simonwillison.net/2026/May/31/the-solution-might-be-cancelling-my-ai-subscription/#atom-everything)**
A more skeptical take, apparently exploring whether stepping back from paid AI tools is a reasonable response to frustration with current products. A useful counterweight to the relentless adoption narrative.

## Security

**[Hackers Simply Asked Meta AI to Give Them Access to High-Profile Instagram Accounts. It Worked](https://simonwillison.net/2026/Jun/1/hackers-simply-asked-meta-ai/#atom-everything)**
Researchers or attackers — the framing matters less than the outcome — found that Meta's AI assistant could be prompted into granting account access it should not have. This is a straightforward prompt injection / social engineering failure at the AI layer, and it will not be the last one involving a major consumer platform.
