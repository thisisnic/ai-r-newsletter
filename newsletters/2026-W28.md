# AI Tooling & R Ecosystem Weekly Digest

A busy week for LLM tooling releases and SQLite utilities, with one notable R package update worth tracking.

---

## LLM Tooling

**[llm 0.31.1](https://simonwillison.net/2026/Jul/9/llm/#atom-everything)** — date unavailable

Simon Willison's `llm` CLI and Python library notched another point release. The tool continues to be one of the more practical ways to interact with a range of language model providers from the command line or Python scripts.

**[llm-meta-ai 0.1](https://simonwillison.net/2026/Jul/9/llm-meta-ai/#atom-everything)** — date unavailable

A new plugin extending `llm` to support Meta AI as a backend provider. Worth watching if Meta's models are on your list of things to evaluate, though at 0.1 expect rough edges.

**[Introducing GPT-Live](https://simonwillison.net/2026/Jul/8/introducing-gptlive/#atom-everything)** — date unavailable

OpenAI announced GPT-Live, a real-time interaction product. The positioning and feature set suggest this is aimed squarely at voice and low-latency use cases rather than batch or API workflows.

**[The new GPT-5.6 family: Luna, Terra, Sol](https://simonwillison.net/2026/Jul/9/gpt-5-6/#atom-everything)** — date unavailable

OpenAI expanded its model lineup with three named variants under the GPT-5.6 banner. Willison's coverage gives a practical read on where each sits in terms of capability and intended use.

## SQLite Tooling

**[sqlite-utils 4.0, now with database schema migrations](https://simonwillison.net/2026/Jul/7/sqlite-utils-4/#atom-everything)** — date unavailable

The headline feature of sqlite-utils 4.0 is built-in schema migration support, something the tool had conspicuously lacked. After several release candidates across the week, the stable release landed alongside a companion 4.1 patch. If you use sqlite-utils in any automated pipeline, the migration support is a genuine quality-of-life improvement.

**[sqlite-migrate 0.2](https://simonwillison.net/2026/Jul/7/sqlite-migrate/#atom-everything)** — date unavailable

A related standalone migration library for SQLite also shipped a new version in the same window, likely coordinated with the sqlite-utils 4.0 work. The two projects are complementary if you need fine-grained migration control outside of sqlite-utils itself.

---

## R Packages

**[rollama 0.3.0](https://github.com/JBGruber/rollama/blob/HEAD/NEWS.md#rollama-0-3-0)** — 2026-07-07

A substantial update to the R interface for Ollama, the local LLM runner. This release adds structured outputs (with a new vignette), logprobs support, response caching, multi-question batching, and a `list_running_models()` function. The package also syncs with recent Ollama API changes and rewrites progress and streaming handling. If you run local models from R, this is worth upgrading to.

## New Models

**[tencent/Hy3](https://simonwillison.net/2026/Jul/6/hy3/#atom-everything)** — date unavailable

Tencent released Hy3, a new model entry from the same family as Hunyuan. Details on benchmarks and availability are sparse in the coverage, but it signals continued activity from Chinese labs on open or semi-open releases.

**[Introducing Muse Spark 1.1](https://simonwillison.net/2026/Jul/9/muse-spark-1-1/#atom-everything)** — date unavailable

Muse Spark 1.1 is a creative-focused model update. The use case appears oriented toward generative and artistic workflows rather than code or analysis, so relevance to a technical audience is limited unless you work adjacent to that space.
