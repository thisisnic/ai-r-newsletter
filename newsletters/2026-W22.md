## LLM Tooling

**[Claude Opus 4.8: 'a modest but tangible improvement'](https://simonwillison.net/2026/May/28/claude-opus-4-8/#atom-everything)** — date unavailable

Anthropic released Claude Opus 4.8, which Simon Willison characterizes as a small but real step forward over its predecessor. Worth tracking if you're benchmarking models for production use, though nothing here suggests a wholesale reason to switch workflows.

**[llm-anthropic 0.25.1](https://simonwillison.net/2026/May/28/llm-anthropic/#atom-everything)** — date unavailable

A point release of the `llm-anthropic` plugin for Simon Willison's `llm` CLI tool. Likely includes compatibility updates for recent Anthropic API changes; useful if you're running Anthropic models from the command line.

**[sqlite AGENTS.md](https://simonwillison.net/2026/May/27/sqlite-agents/#atom-everything)** — date unavailable

Willison highlights the AGENTS.md file from the SQLite project, which documents guidance for AI coding agents working with the codebase. It's a small but telling sign that major open-source projects are now explicitly writing documentation aimed at LLMs rather than humans.

**[Running Python ASGI apps in the browser via Pyodide + a service worker](https://simonwillison.net/2026/May/30/pyodide-asgi-browser/#atom-everything)** — date unavailable

A technical piece on running full Python ASGI applications client-side using Pyodide and a service worker. Relevant for anyone building local-first or offline-capable AI tooling that relies on Python backends.

## Datasette Updates

**[datasette 1.0a30](https://simonwillison.net/2026/May/24/datasette/#atom-everything)** and **[datasette 1.0a31](https://simonwillison.net/2026/May/29/datasette/#atom-everything)** — dates unavailable

Two alpha releases of Datasette dropped in the same week, continuing the slow march toward a stable 1.0. If you're using Datasette for data exploration or as a backend for LLM tooling, it's worth checking the changelogs.

**[datasette-agent 0.1a4](https://simonwillison.net/2026/May/24/datasette-agent/#atom-everything)** — date unavailable

An early alpha of `datasette-agent`, which appears to add agentic/LLM-driven query capabilities to Datasette. Early days, but worth watching if you're interested in natural-language interfaces over SQLite databases.

**[datasette-fixtures 0.1a0](https://simonwillison.net/2026/May/24/datasette-fixtures/#atom-everything)** — date unavailable

Initial release of a fixtures plugin for Datasette, aimed at making test data management easier. Useful for developers building and testing Datasette plugins.

## Security

**[Microsoft Copilot Cowork Exfiltrates Files](https://simonwillison.net/2026/May/26/copilot-cowork-exfiltrates-files/#atom-everything)** — date unavailable

A reported vulnerability in Microsoft's Copilot Cowork feature that allows file exfiltration, covered by Willison as part of his ongoing documentation of prompt injection and AI security issues. A practical reminder that tightly integrated LLM features in productivity software carry real attack surface. Worth reading before deploying Copilot in sensitive environments.

**[How we contain Claude across products](https://simonwillison.net/2026/May/30/how-we-contain-claude/#atom-everything)** — date unavailable

Anthropic published details on how they scope and constrain Claude's behavior across different product contexts. The piece touches on system prompt boundaries and behavioral containment strategies, which is directly relevant to anyone building on the Anthropic API.

## Commentary

**[Choosing to Stay Human](https://www.oneusefulthing.org/p/choosing-to-stay-human)** — 2026-05-26

Ethan Mollick observes that social media is increasingly flooded with AI-generated content that converges on similar patterns and voice. The piece argues for a deliberate choice to keep human authorship legible and distinct, without being preachy about it. A reasonable thing to read if you're thinking about where to draw lines in your own writing workflow.

**[I think Anthropic and OpenAI have found product-market fit](https://simonwillison.net/2026/May/27/product-market-fit/#atom-everything)** — date unavailable

Willison links to or comments on the observation that both Anthropic and OpenAI now have revenue trajectories that suggest genuine product-market fit, not just hype-driven adoption. Worth reading alongside the revenue figure below for context on where the industry actually is.

**[Anthropic's run-rate revenue hits $4.7 billion](https://simonwillison.net/2026/May/29/anthropic/#atom-everything)** — date unavailable

Anthropic's annualized revenue has reached $4.7 billion, a significant number that puts it in credible competition with OpenAI for enterprise AI spend. The growth rate matters more than the absolute figure; the trajectory suggests the API ecosystem is not going anywhere.
